# Version 17.2.3 – Logo Manager ohne Firebase Storage

- Logo-Dateien werden im Browser auf 256 × 256 Pixel verkleinert.
- Speicherung als kompaktes WebP-Data-URL direkt im Firestore-Dokument.
- Kein Blaze-Tarif und kein Firebase Storage erforderlich.
- Direkte Logo-URLs bleiben weiterhin möglich.
- Verwaltete Logos werden als priorisierte Vereinslogos in der App verwendet.
