# Version 18.0.1 – Sponsor Manager Bestandsdaten-Fix

- Der Sponsor Manager lädt jetzt auch bestehende Sponsoren ohne `order`-Feld.
- Die Collection bleibt `sponsors`; keine Migration und keine doppelten Daten.
- Reihenfolge wird clientseitig sortiert. Sponsoren ohne Reihenfolge erscheinen alphabetisch.
- Beim ersten Verschieben oder Bearbeiten kann das `order`-Feld ergänzt werden.
