# kfvClubs – Vereinslogos einrichten

Die App funktioniert weiterhin mit den Logos aus `kfvMatches`. Mit `kfvClubs` können Logos zentral korrigiert oder ergänzt werden.

## Beispiel: TSU Ainet

Collection: `kfvClubs`
Dokument-ID: `ainet`

- `name` (String): `TSU Ainet`
- `normalizedName` (String): `ainet`
- `logoUrl` (String): `/tsu-ainet-logo.png`
- `primaryColor` (String): `#d71920`
- `secondaryColor` (String): `#153a76`
- `stadium` (String): `Sandgrubenstadion Ainet`
- `website` (String): leer oder Vereinswebsite
- `active` (Boolean): `true`

## Beispiel: TSU Dölsach

Dokument-ID: `doelsach`

- `name` (String): `TSU Dölsach`
- `normalizedName` (String): `doelsach`
- `logoUrl` (String): vollständige URL zum Dölsach-Logo
- `primaryColor` (String): optional
- `secondaryColor` (String): optional
- `stadium` (String): optional
- `website` (String): optional
- `active` (Boolean): `true`

Die zentrale Logo-URL hat Vorrang vor dem Logo, das im einzelnen Spiel gespeichert ist.
