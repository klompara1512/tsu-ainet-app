# Version 13.2.0 – KFV/ÖFB Tabellenparser

- Feste Tabellenquellen für KM, Challenge, U17, U12 und U10.
- Kampfmannschaft nutzt die angegebene KFV-Vereinsseite mit ÖFB-Tabellenseite als Rückfallquelle.
- Responsive ÖFB-Tabellen werden auch erkannt, wenn sie nicht als HTML-`table`, sondern als DIV-/ARIA-Zeilen gerendert werden.
- Tabellen mit Saisonstartwerten 0 Spiele / 0:0 Tore / 0 Punkte sind zulässig.
- Vereinslinks, Vereins-IDs und Logos werden aus jeder Tabellenzeile übernommen.
