# Version 18.3.0 Beta 1 – Prematch Manual 7-Day Gate Fix

- Manueller Spielbericht-Sync prüft nun ebenfalls Spiele bis 7 Tage vor Anpfiff.
- `REPORT_FORCE_WINDOW_MINUTES` von 720 auf 10080 Minuten erweitert.
- Fallback im Parser ebenfalls auf 10080 Minuten gesetzt.
- Damit können bereits offiziell veröffentlichte Spielorte und Schiedsrichter mehrere Tage vor dem Spiel übernommen werden.
