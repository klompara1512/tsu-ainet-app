# TSU Ainet App – Version 9.0.0

## Neu
- Modernisierte Startseite mit Vereinszentrale-Badge
- Überarbeiteter Hero-Bereich
- Neue Bezeichnung „Meine TSU Ainet“ für Schnellzugriffe
- Sichtbare Versionsanzeige am unteren Seitenende
- Verbesserte Hover- und Kartenanimationen
- Bestehende KFV-, Kalender-, Logo- und Verwaltungsfunktionen bleiben erhalten

## Installation
1. Projekt sichern.
2. Inhalt dieser ZIP in den Projektordner kopieren.
3. Vorhandene `.env` behalten.
4. `npm install` ausführen.
5. `npm run dev` testen.
6. Danach `npm run build` und `firebase deploy --only hosting`.
