# Version 17.2.4 – Logo Manager Phase 4

- Alle Vereine aus `kfvClubs` werden automatisch im Logo Manager angezeigt.
- Eigene Zuordnungen aus `clubLogos` werden darübergelegt.
- Filter für alle Vereine, fehlende Logos und eigene Logos.
- Offizielle ÖFB/KFV-Logos bleiben sichtbar, bis sie durch ein eigenes Logo ersetzt werden.
- Eigene Logos werden zentral in Kalender, Spielcenter, Tabellen, Dashboard und Teams bevorzugt.
- Spark-kompatibel ohne Firebase Storage.
- Dashboard-TypeScript-Narrowing korrigiert.
