# Version 8.0.0

- Kader-Zuordnung für KM/Kampfmannschaft und Reserve/Challenge robuster gemacht.
- Spieler- und Trainerfotos bleiben enthalten.
- Neuer Fanbereich mit Spielerstatistik, Lieblingsspielern, Live-Spielmodus, Matchblatt, Kalenderexport, Benachrichtigungsfreigabe, Bildergalerie, Videos, Sponsoren, Wetter und Navigation.
- Lieblingsspieler werden kostenlos lokal auf dem Gerät gespeichert.
- Kalenderexport erstellt eine ICS-Datei aus den vorhandenen Spieldaten.

Hinweis: Echte automatische Push-Nachrichten benötigen zusätzlich einen Versanddienst bzw. Firebase Cloud Messaging. Die Browser-Berechtigung und ein lokaler Test sind bereits eingebaut.
