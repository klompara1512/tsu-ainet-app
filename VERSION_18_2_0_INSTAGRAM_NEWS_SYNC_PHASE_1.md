# Version 18.2.0 – Instagram News Sync Phase 1

## Neu

- Automatischer Import aller abrufbaren Beiträge des professionellen Kontos `@tsu.ainet`.
- Offizielle Instagram API mit Instagram Login.
- Bilder, Karussells und Reels mit Vorschaubild.
- Beitragstext, Veröffentlichungsdatum und Original-Link.
- Schutz vor Duplikaten über die Instagram-Media-ID.
- Automatischer GitHub-Workflow ungefähr alle 30 Minuten.
- Statusdokument `settings/instagramNewsSyncStatus`.
- Instagram-Kennzeichnung im Newsbereich.
- Button „Beitrag/Reel auf Instagram ansehen“.

## GitHub Secrets

- `FIREBASE_SERVICE_ACCOUNT`
- `INSTAGRAM_ACCESS_TOKEN`
- `INSTAGRAM_USER_ID` (empfohlen)
