# Version 18.3.0 RC10 – Sponsorenband-Zentrierung

- Sponsorlogos werden innerhalb jeder Laufband-Kachel horizontal und vertikal exakt zentriert.
- Eine eigene Logo-Fläche verhindert Verschiebungen durch unterschiedliche Bildformate.
- PNG-, JPG-, WebP- und automatisch zugeschnittene Logos verwenden dieselbe Ausrichtung.
- Mobile und Desktop nutzen dieselbe Zentrierungslogik.
- Lange Logos bleiben vollständig sichtbar und werden nicht verzerrt.
