# Version 2.3 – KFV Live-Synchronisierung

Neu:
- Offizielle ÖFB/KFV-Vereinswidgets direkt in der App
- Tabellen und Spielpläne für Kampfmannschaft, Challenge, U17, U12, U10 und U8
- automatische Aktualisierung (1–15 Minuten einstellbar)
- Widget-Einrichtung direkt in „KFV Live“
- Widget-URL oder kompletter iframe-Code kann eingefügt werden
- bisherige Firestore-Daten bleiben als „App-Daten“ vollständig erhalten

## Einmalige Einrichtung
1. KFV Live öffnen
2. „Offizielle Live-Daten“ wählen
3. „Einrichten“ öffnen
4. ÖFB/KFV-Widget-URL oder iframe-Code für die jeweilige Mannschaft einfügen
5. speichern

Die Widget-Einstellungen werden in Firestore unter `settings/kfvOfficial` gespeichert.
