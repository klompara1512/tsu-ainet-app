# Version 15.3.0 – Mobile PWA Update

- Mobile Web-App und PWA auf Version 15.3.0 aktualisiert.
- Neuer Service-Worker-Cache verhindert veraltete App-Versionen.
- JavaScript, CSS und Navigation werden bevorzugt aus dem Netzwerk geladen.
- Installierte App prüft beim Öffnen und stündlich auf neue Versionen.
- Sichtbarer Aktualisieren-Button, sobald ein neues Release bereitsteht.
- Verbesserte iPhone-/Android-Safe-Areas und dynamische Bildschirmhöhe.
- Eingabefelder verhindern automatisches Zoomen unter iOS.
- Touch-Ziele sind mobil mindestens 44 Pixel hoch.
- Manifest, Beschreibung und App-Metadaten wurden aktualisiert.
