# Version 10.0.0 – Designsystem

Diese Version baut vollständig auf Version 9.2.0 auf.

## Neu
- Dunkles Anthrazit-/TSU-Blau-Design
- Gelbe Highlights in den Vereinsfarben
- Einheitliche moderne Karten und Navigation
- Modernisierte SVG-Icons ohne zusätzliche Icon-Abhängigkeit
- Aufgeräumte Smartphone-Navigation

## Unverändert
- Spiele, Tabellen und Endstände
- Firebase und Firestore
- GitHub Actions / KFV-Synchronisierung
- Benutzer- und Rollenverwaltung
